# VanillaPlusMobs

Paper plugin adding enhanced versions of five vanilla mobs.

## Features
- 30% chance for eligible naturally spawned mobs to become enhanced.
- Applies in the Overworld, Nether and End.
- Enhanced mobs have configurable health and attack-damage multipliers.
- Optional red glowing outline.
- Bonus vanilla drops, configurable in `config.yml`.
- Persistent enhanced marker survives chunk unloads and restarts.

## Eligible mobs
Zombie, Skeleton, Creeper, Spider and Enderman (exact mob types only).

## Requirements
- Paper 1.21.5 (test before using on later versions)
- Java 21

GitHub Actions builds the plugin and uploads the JAR as a workflow artifact.
